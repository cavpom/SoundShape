# SoundShape — песочница звука

Небольшие браузерные эксперименты, сгруппированные по главам. Глава «Форма звука»: клавиатура До4–Си5 с независимыми переключателями, сбросом выбора, синусоидальным звуком, громкостью и выключением звука без сброса нот. Рядом с выбранными нотами показаны частоты. Неподвижный график показывает сумму волн и, по желанию, каждую волну отдельно; масштабы времени и амплитуды меняются вручную.

## Запуск

Требуется Node.js 22.12+ или совместимая более новая версия.

```powershell
npm install
npm run dev
```

Откройте адрес из терминала. Для проверки типов и сборки: `npm run build`.

## Устройство

- `src/main.ts` — оболочка и общая навигация. Переходы между главами перезагружают страницу; выбранная глава хранится в URL (`?chapter=wave-shape`). Выбор нот при переходе сбрасывается.
- `src/chapters/index.ts` — реестр глав. Для новой главы создайте модуль и добавьте запись в реестр.
- `src/chapters/wave-shape.ts` — первая глава.
- `src/music/notes.ts` — данные нот, без интерфейса.
- `src/ui/piano.ts` — переиспользуемая клавиатура; сообщает выбранные ноты вызывающему коду.

TypeScript проверяет типы, Vite запускает локальный сервер и собирает статические файлы в `dist/`. Серверная часть и UI-фреймворк не используются.

## Звук

`src/music/tuning.ts` вычисляет частоту по формуле `440 * 2 ** ((midi - 69) / 12)` (равномерная темперация, ля4 = 440 Гц). Округление используется только в подписях.

`src/audio/tone-player.ts` — независимый от UI движок Web Audio. AudioContext создаётся после первого выбора ноты. У всех 24 синусоид общий момент старта; выбранные ноты открывают плавные амплитудные огибающие. Пока страница открыта, генераторы продолжают отсчёт фазы, в том числе при выключенном звуке.

Амплитуда каждой ноты фиксирована: 1/24 до общей громкости. Добавление нот не меняет амплитуду уже выбранных, а сумма всех 24 голосов не превышает цифровой диапазон. Поэтому одиночный тон тише полного набора. Переключение звука сохраняет выбор, «Отпустить всё» снимает выбор. При уходе со страницы аудиоконтекст закрывается.

Проверка реального PCM без вывода в динамики: при работающем dev-сервере откройте /tests/audio.html. Проверки используют OfflineAudioContext и сравнивают сигнал движка с формулой, проверяют сумму, выключение звука, сброс, громкость и цифровой диапазон.

## График

`src/music/waves.ts` вычисляет модель `sum(A*sin(2*pi*f*t))` с общей нулевой фазой. В главе «Форма звука» амплитуда каждой ноты равна единице; в главе «Тембр» она задаётся ползунками. `src/ui/wave-plot.ts` отображает её в SVG. График начинается в t=0; это статическая модель, а не текущий буфер динамиков. Плавные огибающие звука в график не включены. Громкость и выключение звука не влияют на изображение.

Начальный диапазон: 0–20 мс и ±4 A. Ручные диапазоны времени: 5, 10, 20, 50, 100 мс; амплитуды: ±1, ±2, ±4, ±8, ±16, ±24 A. Кривые обрезаются только при отображении; о выходе суммы за границы сообщают маркеры и текст. Семплирование обеспечивает не менее 32 отсчётов на период самой высокой выбранной частоты. При смене размера окна SVG перестраивается.

## GitHub Pages

Сайт: https://cavpom.github.io/SoundShape/

Workflow `.github/workflows/pages.yml` проверяет типы, собирает приложение и публикует `dist/` после каждого push в `main`. Его также можно запустить вручную через вкладку Actions. В Settings → Pages источником публикации должен быть GitHub Actions.

Путь к ресурсам берётся из настроек Pages (`base_path`) и передаётся в Vite только при публикации; локальный `npm run dev` работает как прежде. Сборку для проверки GitHub Pages можно получить командой:

```powershell
npm run build -- --base=/SoundShape/
npm run preview -- --base=/SoundShape/
```

Локальный адрес такой проверки: http://127.0.0.1:4173/SoundShape/. Компьютер не нужен для работы опубликованного сайта; звук включается нажатием клавиши в браузере посетителя.

## Тембр

Глава «Тембр»: https://cavpom.github.io/SoundShape/?chapter=timbre (локально: http://127.0.0.1:5173/?chapter=timbre).

Одна основная нота (Ля2–Си5); по умолчанию ля большой октавы, 110 Гц, десять вертикальных регуляторов амплитуд 0–100%, частоты `f0`, `2*f0`, …, `10*f0`. Начальное состояние: первая гармоника 100%, остальные 0%. Кнопка «Сбросить» возвращает только гармоники; основная нота, общая громкость и включение звука сохраняются. На узком экране регуляторы располагаются двумя рядами по пять.

- `src/music/harmonics.ts` — модель спектра и начальное состояние.
- `src/audio/harmonic-player.ts` — десять синусоид с общим началом фазы. Изменения амплитуд, частот и общей громкости сглаживаются. Фиксированный коэффициент 1/10 оставляет запас для всех гармоник; остальные амплитуды не нормализуются при движении отдельного ползунка.
- `src/chapters/timbre.ts` — элементы управления и связь модели со звуком и графиком.
- `src/ui/wave-plot.ts` — общий график для обеих глав. В «Тембре» по умолчанию 0–20 мс и ±2 A; 100% соответствует 1 A. График показывает установившуюся форму с нулевыми начальными фазами, без переходных процессов.

Звук включается отдельной кнопкой; ползунки и график работают без звука. При переходе между главами аудиоконтекст закрывается. Пресеты тембров не добавлены.

При работающем dev-сервере `/tests/timbre.html` проверяет реальные PCM-данные в OfflineAudioContext: соответствие формуле, изменение амплитуд и основной ноты во время звучания, тишину, громкость и отсутствие цифрового клиппинга.

## Тюнер голоса (локальный первый шаг)

Адрес при работающем dev-сервере: http://127.0.0.1:5173/?chapter=voice-tuner

Микрофон включается кнопкой и требует разрешения браузера. Звук не записывается, не отправляется на сервер и не выводится в динамики. Нужен HTTPS или localhost; обычный HTTP по LAN-адресу на телефоне не даёт доступ к микрофону.

Клавиатура До2–До6 показывает ближайшую устойчиво распознанную ноту, частоту и отклонение в центах. Переключение ноты подтверждается за 180 мс после медианной фильтрации трёх кадров; краткий пропуск сигнала удерживается не более 160 мс. Анализ выполняется примерно каждые 40 мс по окну не короче 80 мс. Это параметры сглаживания, а не гарантия сквозной задержки устройства.

- `src/music/pitch.ts` — YIN (разностная функция, накопленная нормализация, первый минимум, параболическое уточнение), RMS в дБFS, перевод частоты в ноту/центы и стабилизация. Поиск основной частоты: 55–1200 Гц.
- `src/audio/microphone-input.ts` — жизненный цикл микрофона и аудиоконтекста, включая отмену запроса доступа и освобождение дорожек. Автоусиление, шумоподавление и эхоподавление запрашиваются выключенными.
- `src/ui/pitch-keyboard.ts` — клавиатура только для отображения. Подсветка обозначает ближайшую ноту, отдельная метка — дробную высоту голоса; позиция интерполируется между реальными центрами соседних клавиш. Плавное слежение центрирует метку, а не округлённую клавишу; его можно выключить. Боковые отступы позволяют центрировать крайние ноты. Шкала центов находится под клавиатурой.
- `src/chapters/voice-tuner.ts` — кнопка микрофона, порог −65…−15 дБFS (по умолчанию −45), индикатор входного уровня и шкала отклонения. Шумовой порог имеет гистерезис 3 дБ. Прямой контроль высоты не гарантирует распознавание шумных/хриплых участков и одновременного фортепиано.

Проверки без доступа к настоящему микрофону: `/tests/pitch.html` — синтетические сигналы, шум, импульс, точность и стабилизация; `/tests/voice-tuner.html` — настоящий интерфейс с синтетическим MediaStream, включая ошибки разрешения, отмену и остановку. Синтетический источник не соединён с динамиками. Реальный голос и конкретный микрофон нужно проверить вручную.
