# SoundShape — песочница звука

Небольшие браузерные эксперименты, сгруппированные по главам. Глава «Форма звука»: клавиатура До4–Си5 с независимыми переключателями, сбросом выбора, синусоидальным звуком, громкостью и выключением звука без сброса нот. Рядом с выбранными нотами показаны частоты. Неподвижный график показывает сумму волн и, по желанию, каждую волну отдельно; масштабы времени и амплитуды меняются вручную.

## Запуск

Требуется Node.js 22.12+ или совместимая более новая версия.

```powershell
npm install
npm run dev
```

Откройте адрес из терминала. Для проверки типов и сборки: `npm run build`.

## Устройство

- `src/main.ts` — оболочка и общая навигация. Переходы между главами перезагружают страницу; выбранная глава хранится в URL (`?chapter=wave-shape`). Выбор нот при переходе сбрасывается.
- `src/chapters/index.ts` — реестр глав. Для новой главы создайте модуль и добавьте запись в реестр.
- `src/chapters/wave-shape.ts` — первая глава.
- `src/music/notes.ts` — данные нот, без интерфейса.
- `src/ui/piano.ts` — переиспользуемая клавиатура; сообщает выбранные ноты вызывающему коду.

TypeScript проверяет типы, Vite запускает локальный сервер и собирает статические файлы в `dist/`. Серверная часть и UI-фреймворк не используются.

## Звук

`src/music/tuning.ts` вычисляет частоту по формуле `440 * 2 ** ((midi - 69) / 12)` (равномерная темперация, ля4 = 440 Гц). Округление используется только в подписях.

`src/audio/tone-player.ts` — независимый от UI движок Web Audio. AudioContext создаётся после первого выбора ноты. У всех 24 синусоид общий момент старта; выбранные ноты открывают плавные амплитудные огибающие. Пока страница открыта, генераторы продолжают отсчёт фазы, в том числе при выключенном звуке.

Амплитуда каждой ноты фиксирована: 1/24 до общей громкости. Добавление нот не меняет амплитуду уже выбранных, а сумма всех 24 голосов не превышает цифровой диапазон. Поэтому одиночный тон тише полного набора. Переключение звука сохраняет выбор, «Отпустить всё» снимает выбор. При уходе со страницы аудиоконтекст закрывается.

Проверка реального PCM без вывода в динамики: при работающем dev-сервере откройте /tests/audio.html. Проверки используют OfflineAudioContext и сравнивают сигнал движка с формулой, проверяют сумму, выключение звука, сброс, громкость и цифровой диапазон.

## График

`src/music/waves.ts` вычисляет модель `sum(sin(2*pi*f*t))` с единичной амплитудой каждой ноты и общей нулевой фазой. `src/ui/wave-plot.ts` отображает её в SVG. График начинается в t=0; это статическая модель, а не текущий буфер динамиков. Плавные огибающие звука в график не включены. Громкость и выключение звука не влияют на изображение.

Начальный диапазон: 0–20 мс и ±4 A. Ручные диапазоны времени: 5, 10, 20, 50, 100 мс; амплитуды: ±1, ±2, ±4, ±8, ±16, ±24 A. Кривые обрезаются только при отображении; о выходе суммы за границы сообщают маркеры и текст. Семплирование обеспечивает не менее 32 отсчётов на период самой высокой выбранной частоты. При смене размера окна SVG перестраивается.

## GitHub Pages

Сайт: https://cavpom.github.io/SoundShape/

Workflow `.github/workflows/pages.yml` проверяет типы, собирает приложение и публикует `dist/` после каждого push в `main`. Его также можно запустить вручную через вкладку Actions. В Settings → Pages источником публикации должен быть GitHub Actions.

Путь к ресурсам берётся из настроек Pages (`base_path`) и передаётся в Vite только при публикации; локальный `npm run dev` работает как прежде. Сборку для проверки GitHub Pages можно получить командой:

```powershell
npm run build -- --base=/SoundShape/
npm run preview -- --base=/SoundShape/
```

Локальный адрес такой проверки: http://127.0.0.1:4173/SoundShape/. Компьютер не нужен для работы опубликованного сайта; звук включается нажатием клавиши в браузере посетителя.
